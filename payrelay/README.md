# x.erp 收款助手（个人免签）

旧安卓手机监听微信/支付宝到账通知，回调云备份服务，按金额自动匹配订单并发授权码。

## 安装

1. 安装 `xerp-payrelay-1.0.3.apk`。
2. 打开电脑后台 `https://www.zhaoyoucai.xyz/xerp-cloud/admin` →「收款助手」→ 添加，复制显示的 **ID** 和 **密钥**。
3. 手机 App 填入服务器地址（默认 `https://www.zhaoyoucai.xyz/xerp-cloud`）、ID、密钥，点「保存并启动」；也可以扫描配置二维码后点「粘贴配置」自动填入。
4. 点「打开通知使用权」，在系统设置里勾选「x.erp 收款助手」。
5. 点「发送测试心跳」，显示连接成功即可。

## 手机设置

- 微信/支付宝允许通知，锁屏也显示通知内容
- 关闭本 App 的电池优化，允许后台运行
- 保持联网；重启后会自动启动
- 收款微信/支付宝保持登录

## 原理

- 付款页给每笔订单加 0.01～0.99 元随机尾数，客户必须精确支付
- 手机收到「收款到账 xx 元」通知，用 HMAC 签名回调服务器
- 服务器匹配 30 分钟内同金额的待付款订单，自动生成授权码
- 购买页轮询订单，付款后直接显示授权码

## 限制

- 依赖手机通知，系统杀后台/隐藏通知会漏单
- 回调失败会自动重试 3 次，仍失败会写进 App 里的「查看失败记录」，不再静默丢单
- 退款、风控、账户限制要人工处理
- 不符合微信/支付宝自动化条款，只适合小量临时使用
- 长期稳定请办个体工商户，接官方商户号
